# Cisco Packet Tracer Labs

A collection of hands-on networking labs created using **Cisco Packet Tracer** as I learn and explore computer networking.

##  Objectives

- Understand fundamental networking concepts.
- Practice designing and configuring network topologies.
- Learn IP addressing and subnetting.
- Explore routers, switches, and end devices.
- Document practical networking exercises and lessons learned.

##  Repository Structure

```text
Cisco-Packet-Tracer-Labs/
├── README.md
├── 01-basic-network/
│   ├── basic-network.pkt
│   └── README.md
└── ...
```

Each lab will contain its Packet Tracer project file and, where useful, documentation explaining the topology, configuration, and results.
